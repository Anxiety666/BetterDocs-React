# Commandes & Raccourcis Importants

- Catégorie : Jeu (commandes)

---

🪄 Commandes & Raccourcis Importants


* Appuyez sur K en jeu puis allez dans le menu de configuration pour consulter la liste complète des touches et accéder à des options supplémentaires.
* Tapez /wandcreator dans le chat pour générer une nouvelle baguette.
* Pour le menu admin si vous avez les perms : F1
* Pour le menu animation si vous avez les perms : F9
* Pour le mode réalisateur : F8
* Faire disparaître le nom des joueurs : O
🏃 Mouvements & Déplacements
* Avancer : Z
* Reculer : S
* Aller à gauche : Q
* Aller à droite : D
* Courir : Maj
* Marcher : Alt
* Sauter : Espace
* S'accroupir : Ctrl
* Nager / Plonger : E
⚔️ Actions & Combats
* Interagir : E
* Attaque principale : Clic Gauche (Souris G)
* Viser : Clic Droit (Souris D)
* Sortir / Ranger la baguette : A
* Parer / Parade : F
* Lâcher / Jeter un objet : G
🧹 Balai & Vol
* Monter / Descendre du balai : B
* Freiner : S
* Freiner doucement : S
* Freinage aérien : Espace
* Incliner à gauche / droite : A / D
🧪 Potions & Barre d'action
* Potion 1 : 7
* Potion 2 : 8
* Potion 3 : 9
* Barre précédente : Page Préc.
* Barre suivante : Page Suiv.


📜 Menus & Interface
* Menu principal : Échap
* Inventaire : I
* Grimoire (Sorts) : K
* Arbre de compétences : J
* Carnet scolaire : L
* Vie scolaire : V
* Chat : T
* Afficher le curseur : Clic Molette (Souris M)
* Menu OST : M
